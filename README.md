# Veloce — совместный просмотр

Комнаты по ссылке: синхронный плеер, чат (пузырь справа внизу), голосовой звонок с камерой,
каталог аниме (Shikimori) и фильмов/сериалов (TMDB), выбор озвучки и серии.
Сервер без зависимостей — `npm install` не нужен, нужен только Node.js 20+.

## Запуск на компьютере
    node server.js
Откройте http://localhost:3000, скопируйте ссылку комнаты (кнопка 🔗) и откройте во второй вкладке.

## Выложить в интернет бесплатно (Render)
1. Создайте репозиторий на github.com и загрузите в него все файлы из этой папки
   (Add file → Upload files; папки `public`, `data`, `test` тоже).
2. Зайдите на render.com → войдите через GitHub → New + → **Web Service** → выберите репозиторий.
3. Настройки: Runtime **Node**, Build Command — оставьте пустым (или `echo ok`),
   Start Command — `node server.js`, Instance Type — **Free**.
   (Если в репозитории есть `render.yaml`, Render предложит всё это автоматически: New + → Blueprint.)
4. Create Web Service. Через пару минут получите адрес вида `https://veloce-xxxx.onrender.com`.
   Он сразу открывается по https — а голос и камера работают только по https.
5. Откройте адрес, нажмите «Войти», отправьте ссылку друзьям.

Особенность бесплатного тарифа: после 15 минут без посетителей сервис «засыпает»,
первое открытие после сна занимает около минуты. Комнаты при этом сбрасываются.

## Каталог
- **Аниме** — работает сразу (Shikimori, ключ не нужен).
- **Фильмы и сериалы** — зарегистрируйтесь на themoviedb.org → Settings → API → получите ключ,
  в Render: Environment → добавьте `TMDB_API_KEY`.
- Видео для тайтлов подключаются в `data/sources.json` (формат — в самом файле). Ключ тайтла
  (например `shiki:5114` или `tmdb:movie:603`) показывается при наведении на карточку и в окне «нет видео».
  Озвучки — это список `dubs`, у каждой свои серии. Поддерживаются mp4 и HLS (.m3u8) по https;
  у сервера, откуда берётся видео, должен быть разрешён CORS/воспроизведение на чужих сайтах.
- Любое видео можно включить сразу для всей комнаты кнопкой «＋ Ссылка».
- **YouTube, Rutube, VK Видео:** вставьте обычную ссылку на ролик в «＋ Ссылка» (или в `data/sources.json`
  в поле `src` серии) — откроется встроенный плеер сервиса, Play/пауза/перемотка синхронизируются.
  У таких роликов управление (громкость, полный экран, качество) — родное, а озвучки и серии выбирает автор.
  Ссылки на VK лучше брать из «Поделиться → Экспортировать» (с `hash`), обычные ссылки работают не у всех роликов.
  Если автор запретил встраивание, плеер покажет ошибку — это ограничение сервиса.
- Подключайте только то, на показ чего у вас есть права.

## Голос
Работает напрямую между участниками (до 10 человек), через публичный STUN. Если у кого-то
звук не соединяется (мобильный интернет, строгий роутер) — нужен TURN-сервер: добавьте в Render
переменные `TURN_URLS` (например `turn:host:3478`), `TURN_USERNAME`, `TURN_CREDENTIAL`
(бесплатный пакет есть у metered.ca или Open Relay).
